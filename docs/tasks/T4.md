## Görev

altyapısını yaz.

## Yazılacaklar

### `Shell/RegistryBackup.cs`
- `string CreateBackup(IEnumerable<string> hkcuSubKeys)` → `%APPDATA%\Runly\backups\assoc-<yyyyMMdd-HHmmss>.reg`
- **`reg.exe export` çağırma.** `.reg` metnini elle üret: `Windows Registry Editor Version 5.00`
  başlığı, `[HKEY_CURRENT_USER\...]` blokları, değer tipleri (`REG_SZ` → `"ad"="değer"`,
  `REG_DWORD` → `"ad"=dword:00000001`, `REG_BINARY` → `hex:`), string kaçışları (`\` → `\\`, `"` → `\"`).
- **Kritik:** yedek alınırken var **olmayan** anahtarlar için `[-HKEY_CURRENT_USER\...]` (silme)
  satırı yazılmalı. Yoksa geri yükleme, Runly'nin eklediği anahtarları silmez.
- `void RestoreBackup(string regFilePath)` → `.reg` dosyasını **kendi parser'ınla** uygula
  (`regedit /s` UAC ve sessiz başarısızlık sorunları yaratır). Parser yalnızca HKCU altını
  kabul etsin; başka kök görürse throw etsin (güvenlik).
- `IReadOnlyList<BackupInfo> ListBackups()` → tarih sıralı.

### `Shell/UserChoiceInspector.cs`
- `UserChoiceState Check(string extension)` →
  `HKCU\SOFTWARE\Microsoft\Windows\CurrentVersion\Explorer\FileExts\<ext>\UserChoice` var mı,
  `ProgId` değeri ne.
- Dönüş: `None` / `OwnedByRunly` (ProgId `Runly.Script.*`) / `OwnedByOther(progId, friendlyName)`.
- `friendlyName` çözümlemesi: ProgId → `HKCR\<progId>\(default)`; AppX ProgId'leri
  (`AppX...`) için "bir Microsoft Store uygulaması" de, çözmeye uğraşma.
- **Bu makinede `.ps1` = `AppXxf01pj590w7z9mxmyv3nx0a9ewj3e51g` (Store Not Defteri).
  Bu senaryo mutlaka doğru raporlanmalı.**

### `Shell/ShellRegistrar.cs` — `IShellRegistrar`

`Install(config, exePath)`:
1. Etkin + yorumlayıcısı bulunan uzantıları belirle. Yorumlayıcısı bulunamayanı **atla** ve
   sonuçta bildir.
2. Dokunulacak tüm anahtar yollarını topla → `RegistryBackup.CreateBackup(...)`.
3. Her uzantı için ProgID ağacını yaz (SPEC §9 — `open`, `runas`, `edit`, `runlyargs` fiilleri,
   `DefaultIcon`, Türkçe `MUIVerb` metinleri).
4. `Applications\Runly.exe` kaydı + `SupportedTypes` + `RegisteredApplications` +
   `Capabilities\FileAssociations`.
5. `.ext\OpenWithProgids\Runly.Script.<ext>` **her zaman** yazılır (Birlikte aç listesinde
   görünmenin şartı).
6. `UserChoice` durumu:
   - `None` → `.ext\(default)` = ProgID yaz. Sonuç: `Bound`.
   - `OwnedByRunly` → zaten bizim, `Bound`.
   - `OwnedByOther` → **`.ext\(default)`'a dokunma** (nasılsa UserChoice ezer, ayrıca
     kafa karıştırıcı yan etki üretir). Sonuç: `NeedsUserChoice`.
7. `SHChangeNotify(SHCNE_ASSOCCHANGED, SHCNF_IDLIST, IntPtr.Zero, IntPtr.Zero)` çağır.
8. `InstallResult` dön: yedek yolu, uzantı başına durum listesi, atlananlar ve nedenleri.

`Uninstall()`:
1. Runly'nin yazdığı tüm anahtarları sil (ProgID'ler, Applications\Runly.exe, Capabilities,
   RegisteredApplications değeri, OpenWithProgids girdileri, `.ext\(default)` bizimse temizle).
2. En son yedeği uygulama seçeneği (`UninstallOptions.RestoreBackup`) — **varsayılan kapalı**.
   Gerekçe: `.js` eskiden `WScript.exe`'ye bağlıydı, bu kötü bir varsayılandı; kullanıcı
   isterse geri döner.
3. `SHChangeNotify`.

`GetStatus(config)`:
- Uzantı başına: yorumlayıcı bulundu mu + yolu, `Bound` / `NeedsUserChoice` / `NotBound`.
- **Karar K6:** `ExtensionStatus` modeline `string? UserChoiceOwnerName { get; init; }` ekle
  (T1 modeline izin verilen tek ekleme — yönetici onayı var). `NeedsUserChoice` durumunda
  UserChoice sahibinin okunabilir adını doldur; AppX ProgId'lerinde
  "bir Microsoft Store uygulaması" yaz. T5 bunu turuncu satır metninde kullanacak.
- GUI (T5) bu listeyi doğrudan tabloya basacak.

### `Shell/OpenWithDialog.cs`
- `shell32.dll` → `SHOpenWithDialog(hwnd, ref OPENASINFO)` P/Invoke.
  `OAIF_ALLOW_REGISTRATION | OAIF_REGISTER_EXT | OAIF_EXEC` bayrakları.
- `bool ShowForExtension(IntPtr owner, string sampleFilePath)` — Windows bu diyaloğu bir
  **dosya** üzerinden ister; verilen örnek dosya yoksa `%TEMP%` altında o uzantıda geçici bir
  dosya üret, diyaloğu göster, sonra sil.
- Bu, `.ps1` gibi UserChoice'ı olan uzantıları bağlamanın **tek meşru yolu**. Kullanıcı
  diyalogda Runly'yi seçip "Her zaman bu uygulamayı kullan" işaretler.

## Kesin yasaklar

- `UserChoice` hash'ini üretmeye/kırmaya **çalışma**. `Hash` değerini yazma. Anahtarı silme.
  (Silmek Explorer'ı geçici bozar ve Windows onu yeniden üretir.)
- `HKLM`'ye yazma. Yönetici hakkı isteme. Her şey HKCU altında.
- `regedit /s`, `reg.exe import/add` çağırma — hepsi kendi kodunla.
- Sistem genelinde `ExecutionPolicy` değiştirme.

## Testler

`tests/Runly.Core.Tests/Shell/`:

- `UserChoiceInspectorTests` — sahte registry yerine bir `IRegistryAccessor` arayüzü arkasından

**Gerçek registry'ye dokunan otomatik test yazma.** Install/Uninstall elle test edilecek.

## Elle test (raporla)

1. Temiz durumda `Install` → `.js` ve `.py` `Bound` olmalı, `.ps1` `NeedsUserChoice`.
2. Explorer'da `.js` dosyasına çift tık → Runly açılıyor mu (T3 hazırsa tam akış, değilse
   `shell\open\command` değerini `reg query` ile doğrula).
3. Yedek dosyasını aç, içeriğinin geçerli `.reg` olduğunu ve `[-HKEY...]` satırları içerdiğini gör.
4. `Uninstall` → `reg query` ile tüm anahtarların gittiğini doğrula, `.js` çift tık eski
   davranışına döndü mü bak.
5. `SHOpenWithDialog`'u `.ps1` için çağır, diyalog açılıyor mu gör (seçimi tamamlamana gerek yok).
