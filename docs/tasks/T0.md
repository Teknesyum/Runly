# T0 — Ortam Kurulumu

**Model: Haiku** · Bağımlılık: yok · Tahmini süre: 10 dk

## Görev

Runly projesi C# / .NET 8 ile yazılacak. Bu makinede .NET **runtime** var ama **SDK yok**.
SDK'yı kur ve doğrula.

## Adımlar

1. .NET 8 SDK'yı kur:
   ```bash
   winget install --id Microsoft.DotNet.SDK.8 --accept-source-agreements --accept-package-agreements
   ```
2. Yeni bir kabuk açıp doğrula (PATH yenilenmesi gerekir):
   ```bash
   dotnet --version && dotnet --list-sdks
   ```
   Beklenen: `8.0.x` görünmeli.
3. AOT derlemesi için Visual Studio C++ build araçları gerekir. Var mı kontrol et:
   ```bash
   ls "C:/Program Files (x86)/Microsoft Visual Studio/2022" "C:/Program Files/Microsoft Visual Studio/2022" 2>/dev/null
   ```
   Eğer MSVC yoksa şunu kur (büyük indirme, ~2 GB — kullanıcıya önce haber ver ve onay al):
   ```bash
   winget install --id Microsoft.VisualStudio.2022.BuildTools --override "--quiet --add Microsoft.VisualStudio.Workload.VCTools --includeRecommended"
   ```
4. Çalıştığını kanıtla: `%TEMP%` altında geçici bir konsol projesi oluştur, AOT yayınla, çalıştır:
   ```bash
   cd "$TEMP" && dotnet new console -o aottest && cd aottest && dotnet publish -c Release -r win-x64 /p:PublishAot=true
   ```
   Çıkan exe'yi çalıştırıp "Hello, World!" gördüğünü doğrula, sonra klasörü sil.

## Kabul kriteri

- `dotnet --list-sdks` çıktısında 8.0.x var.
- AOT publish hatasız tamamlandı ve üretilen exe çalıştı.

## Yapma

- Proje dosyalarına dokunma. Bu paket sadece ortam kurulumudur.
- MSVC kurulumunu kullanıcıdan onay almadan başlatma.
