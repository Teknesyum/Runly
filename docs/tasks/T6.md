# T6 — Build/Kurulum Scriptleri, İkonlar, Örnekler, README

**Model: Haiku** · Bağımlılık: T3, T4 · Tahmini süre: 1 saat

> Bu paket mekanik iş. C# koduna dokunma; sadece `scripts/`, `assets/`, `samples/`, `README.md`.

## 1. `scripts/build.ps1`

- Parametre: `-Configuration Release` (varsayılan), `-Output "dist"`
- Yaptıkları:
  1. `dotnet test` — başarısızsa dur.
  2. `dotnet publish src/Runly.Launcher -c $Configuration -r win-x64 /p:PublishAot=true`
     **Karar K8:** bu adım Defender taraması yüzünden `MSB3061 / Access denied` ile bir kez
     başarısız olabilir. 3 denemeye kadar, aralarında 500 ms bekleyerek retry yap.
  3. `dotnet publish src/Runly.Settings -c $Configuration -r win-x64 --self-contained`
  4. Çıktıları `dist/` altında topla: `Runly.exe`, `RunlySettings.exe` + bağımlılıkları,
     `assets/`, `README.md`
  5. Sonunda `dist/` içeriğini ve `Runly.exe` boyutunu yazdır.
- Her adımda hata olursa anlaşılır Türkçe mesajla dur (`exit 1`).

## 2. `scripts/install.ps1`

- `dist/` içeriğini `%LOCALAPPDATA%\Programs\Runly\` altına kopyalar.
- Sonra `RunlySettings.exe`'yi başlatır (kurulum işini GUI yapar — script registry'ye
  **dokunmaz**).
- `-Silent` bayrağı verilirse GUI yerine `Runly.exe --install` çağırır.
  (Bu bayrak T3'te varsa kullan; yoksa raporda "yok" de ve GUI yolunu bırak.)

## 3. `scripts/uninstall.ps1`

- Önce `RunlySettings.exe`'yi "kaldır" moduna yönlendir, sonra program klasörünü siler.
- `%APPDATA%\Runly` verilerini silmeden önce sorar (yedekler orada).

## 4. `assets/` ikonları

Gerekli: `runly.ico` (uygulama) + uzantı ikonları `js.ico`, `ts.ico`, `ps1.ico`, `py.ico`,
`sh.ico`, `generic.ico`.

- Harici ikon indirme, telif riski alma. Kendin üret: her biri için basit bir SVG yaz
  (koyu zemin, ortada uzantı kısaltması, dile göre renk — js sarı, ts mavi, ps1 lacivert,
  py yeşil/mavi, sh gri), sonra PowerShell + `System.Drawing` ile PNG'ye çevirip çok boyutlu
  `.ico` üret (16/32/48/256).
- Bunu yapan `scripts/make-icons.ps1` dosyasını da yaz ki tekrar üretilebilsin.
- Üretim başarısızsa: tek renkli düz kare ikonlar da kabul — ama `.ico` dosyaları **var olmalı**,
  T4'ün `DefaultIcon` kaydı buna bağlı.

## 5. `samples/` — kabul testleri için

SPEC §12'deki senaryoları besleyecek dosyalar:
- `hello.js` — konsola Türkçe karakterli mesaj + `process.argv` argümanlarını yazar, exit 0
- `fail.js` — hata mesajı yazar, `process.exit(1)`
- `slow.js` — 3 saniye bekler (bekleme davranışı testi)
- `args.js` — aldığı argümanları numaralandırarak yazar
- `hello.ps1` — Türkçe mesaj + argümanlar
- `hello.py` — Türkçe mesaj + `sys.argv`
- `shebang-test` (uzantısız) — `#!/usr/bin/env node` shebang'li, mesaj yazar
- `Türkçe klasör/boşluklu ad.js` — yol kaçış testi
- `README.md` — hangi dosyanın hangi senaryoyu test ettiği tablosu

## 6. Kök `README.md`

Bölümler: Runly nedir · Neden gerekli (Windows'un `.ps1`/`.js` davranışı) · Kurulum ·
Kullanım (çift tık + sağ tık fiilleri) · Güvenlik modeli (3 mod + MOTW kuralı, dürüstçe:

akışı (adım adım, ekran görüntüsüz de anlaşılır) · Ayarlar dosyası konumu · Kaldırma ·
Sorun giderme (yorumlayıcı bulunamadı, çift tık hâlâ eski uygulamayı açıyor, ExecutionPolicy).

Türkçe yaz. Abartılı pazarlama dili kullanma, düz anlatım.

## Kabul kriteri

- `scripts/build.ps1` temiz bir kabukta baştan sona çalışıyor ve `dist/` üretiyor.
- `assets/` altında 6 `.ico` dosyası mevcut ve Explorer'da düzgün görünüyor.
- `samples/` dosyalarının hepsi kendi yorumlayıcısıyla elle çalıştırıldığında beklendiği gibi
  davranıyor (`node samples/hello.js` vb. — Runly üzerinden değil, doğrudan).

## Yapma

- `src/` veya `tests/` altına dokunma.
- İnternetten ikon/asset indirme.
