# T1 — Solution İskeleti + Core Sözleşmeleri

**Model: Opus** · Bağımlılık: T0 · Tahmini süre: 1-1.5 saat

> Başlamadan `docs/SPEC.md`'yi baştan sona oku. Bu paket projenin omurgasıdır; buradaki
> her arayüz sonraki 6 paketin sözleşmesidir. Yanlış tasarım geri dönüşü en pahalı hatadır.

## Görev

Çözümü kur, tüm projeleri oluştur, `Runly.Core`'un **arayüzlerini, modellerini ve varsayılan
konfigürasyonunu** yaz. Mantık implementasyonu T2'de yapılacak — burada gövdeler
`throw new NotImplementedException()` olabilir, **ama arayüzler eksiksiz ve nihai olmalı.**

## Oluşturulacaklar

```
Runly.sln
src/Runly.Core/Runly.Core.csproj            net8.0, Nullable=enable, TreatWarningsAsErrors
src/Runly.Launcher/Runly.Launcher.csproj    net8.0, Exe, PublishAot, InvariantGlobalization
src/Runly.Settings/Runly.Settings.csproj    net8.0-windows, WinExe, UseWindowsForms
tests/Runly.Core.Tests/…                    xUnit, Core'a referans
```

Launcher ve Settings şimdilik sadece derlenen boş `Main`/`Form` içersin.

### Runly.Core içeriği

**Models/** (hepsi `record` veya immutable class):
- `RunlyConfig` — SPEC §5.1'deki tüm alanlar, `Dictionary<string, ExtensionMapping> Extensions`
- `ExtensionMapping` — Interpreter, Args, Enabled, Icon
- `TrustStore` — TrustedFolders (list), TrustedFiles (dict → `TrustedFileEntry`)
- `TrustedFileEntry` — Sha256, AddedUtc
- `SecurityMode` enum — AlwaysAsk, TrustOnFirstUse, NeverAsk
- `KeepWindowMode` enum — Always, OnError, Never
- `LaunchRequest` — ScriptPath, Verb, ScriptArgs (string[]), NoWait
- `LaunchVerb` enum — Run, RunAs, Edit, PromptArgs
- `ResolvedInterpreter` — ExecutablePath, ArgumentLine, Source (enum: Shebang, Config, None)
- `SecurityDecision` — Allow (bool), Reason (enum), RememberFile, RememberFolder, StripMotw
- `SecurityVerdict` enum — Trusted, NeedsPrompt, MotwBlocked, Changed
- `ScriptInfo` — Path, Extension, SizeBytes, ModifiedUtc, Sha256, HasMotw, ZoneId, FirstLines
- `ExitCode` static class — Success=0, ScriptFailed=1, UsageError=2, NoInterpreter=3, UserCancelled=4

**Abstractions/** (arayüzler — T2/T3/T5 bunları implemente eder ve mock'lar):
- `IConfigStore` → `RunlyConfig Load()`, `void Save(RunlyConfig)`, `string ConfigPath { get; }`
- `ITrustStore` → `Load()`, `Save()`, `bool IsTrusted(ScriptInfo)`, `void TrustFile(ScriptInfo)`, `void TrustFolder(string)`
- `IInterpreterResolver` → `ResolvedInterpreter Resolve(ScriptInfo, RunlyConfig, string[] args)`
- `IPathSearcher` → `string? Find(string exeName)` (PATH/PATHEXT taraması + cache)
- `IScriptInspector` → `ScriptInfo Inspect(string path)` (boyut, hash, MOTW, ilk 100 satır, shebang)
- `IMotwService` → `bool HasMotw(string)`, `int? GetZoneId(string)`, `void Strip(string)`
- `ISecurityGate` → `SecurityVerdict Evaluate(ScriptInfo, RunlyConfig, ITrustStore)`
- `IProcessLauncher` → `int Launch(ResolvedInterpreter, string workingDir, bool elevated)`
- `IShellRegistrar` → `InstallResult Install(RunlyConfig, string exePath)`, `UninstallResult Uninstall()`, `IReadOnlyList<ExtensionStatus> GetStatus(RunlyConfig)`
- `ExtensionStatus` record → Extension, InterpreterFound, InterpreterPath, Bound (enum: Bound, NeedsUserChoice, NotBound)
- `IDialogService` → `SecurityDecision? AskSecurity(ScriptInfo, string commandLine, SecurityVerdict)`, `string? AskArgs(ScriptInfo)`, `void ShowError(string title, string body)`
- `ILogger` → `void Info(string)`, `void Warn(string)`, `void Error(string, Exception?)`

**Defaults/**
- `DefaultConfig.Create()` → SPEC §5.1'deki tabloyu birebir üreten statik metot.
- Bu makinede kurulu olanlar (`node`, `py`, `powershell`) `enabled: true`, diğerleri `false`.

**Json/**
- `RunlyJsonContext` — `[JsonSerializable]` source-generated context. **AOT için şart.**
  `RunlyConfig` ve `TrustStore` için tanımlı olmalı. `JsonSerializerOptions`: camelCase değil,
  şemadaki isimler birebir; `WriteIndented = true`; `ReadCommentHandling = Skip`;
  `AllowTrailingCommas = true`.

**Paths/**
- `RunlyPaths` — `AppDataDir`, `ConfigPath`, `TrustPath`, `LogPath`, `BackupDir`, `CachePath`.
  `%APPDATA%\Runly` altında; klasör yoksa oluşturan `EnsureCreated()` metodu.

## Kurallar

- `Runly.Core` **hiçbir** UI/Console API'si kullanmaz, `net8.0` (windows-agnostic TFM) hedefler —
  Win32 P/Invoke'lar `[SupportedOSPlatform("windows")]` ile işaretlenir.
- Reflection tabanlı JSON kullanma (AOT kırar). Sadece source-generated context.
- Her public tipe tek satır XML doc.
- `dotnet build` sıfır warning ile geçmeli.

## Ayrıca yaz

`tests/Runly.Core.Tests` içinde `DefaultConfigTests`: varsayılan config'in serialize/deserialize
round-trip'inin kayıpsız olduğunu ve 14 uzantının hepsinin bulunduğunu doğrulayan 2-3 test.
Bu, JSON context'in AOT-uyumlu kurulduğunun kanıtı.

## Kabul kriteri

- `dotnet build -c Release` yeşil, sıfır warning.
- `dotnet test` yeşil.
- `dotnet publish src/Runly.Launcher -c Release -r win-x64 /p:PublishAot=true` hatasız
  (boş Main ile bile olsa AOT zincirinin çalıştığını kanıtla).
