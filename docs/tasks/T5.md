# T5 — Ayarlar GUI (RunlySettings.exe)

**Model: Sonnet** · Bağımlılık: T2, T4 · Tahmini süre: 2-3 saat

> `docs/SPEC.md` §10 bu paketin şartnamesidir. Tüm kullanıcı metinleri **Türkçe**.
> `Runly.Core`'daki servisleri kullan, mantığı GUI'de yeniden yazma.

## Görev

`src/Runly.Settings` içinde WinForms tek pencereli ayar/kurulum uygulamasını yaz.

## Pencere düzeni

`MainForm`, 960x680, minimum 800x600, yeniden boyutlandırılabilir, DPI-aware (PerMonitorV2).
Tasarımcı dosyası kullanma — layout'u koddan kur (`TableLayoutPanel` + `Dock`), tek dosyada
okunabilir olsun.

### 1. Üst durum şeridi
- `Runly kurulu ✅` / `Runly kurulu değil` · exe yolu · sürüm · config yolu (tıklayınca klasörü açar).

### 2. Uzantı tablosu (`DataGridView`, ana alan)
Kolonlar: `Etkin` (checkbox) · `Uzantı` · `Yorumlayıcı` (düzenlenebilir) · `Bulundu` (✓ + yol / ✗) ·
`Argümanlar` (düzenlenebilir) · `Durum`.

`Durum` hücre renkleri: `Bağlı` yeşil · `Windows onayı gerekiyor` turuncu · `Bağlı değil` gri.
Turuncu satırlarda hücrede bir buton: **"Windows'a sor"** → `OpenWithDialog.ShowForExtension`.
Yanına açıklama metni:

> Windows bu uzantı için önceden bir uygulama seçmiş. Güvenlik gereği bunu program
> değiştiremez. Açılan pencereden **Runly**'yi seçip "Her zaman bu uygulamayı kullan"
> kutusunu işaretleyin.

Altta `Uzantı ekle` / `Seçili uzantıyı sil` butonları.

### 3. Güvenlik paneli (`GroupBox`)
- Radio: `Her seferinde sor` / `İlk seferde sor, sonra güven` (varsayılan) / `Hiç sorma`
- `Hiç sorma` seçilince kırmızı ikonlu onay diyaloğu:
  > Bu ayarla, çift tıkladığınız her script hiçbir soru sorulmadan çalışır. İnternetten
  > indirilmiş dosyalar yine de uyarı gösterir. Devam edilsin mi?
  Varsayılan buton `Hayır`.
- `Güvenilen klasörler` listesi: ekle (klasör seçici) / çıkar.
- `Güvenilen dosyalar: {n} adet` + `Tümünü temizle` butonu.

### 4. Davranış paneli
- `Pencereyi açık tut`: `Her zaman` / `Sadece hata olursa` (varsayılan) / `Hiçbir zaman`
- `Düzenleyici komutu` metin kutusu (varsayılan `code`) + `Test et` butonu
- `Günlük tut` checkbox + `Günlük klasörünü aç`

### 5. Alt bar
`Kur / Güncelle` · `Kaldır` · `Yedekten geri yükle` · `Kaydet` · `Kapat`

- `Kur`: `IShellRegistrar.Install` → sonuç diyaloğunda satır satır ne yapıldığı
  (bağlanan uzantılar, atlananlar + neden, yedek dosya yolu).
- `Kaldır`: onay diyaloğu + `Yedeği de geri yükle` checkbox'ı (varsayılan **kapalı**,
  açıklama: "Kapalı bırakırsanız bu uzantılar ilişkisiz kalır — `.js` eski `WScript` davranışına
  dönmez.").
- `Yedekten geri yükle`: yedek listesi (tarih sıralı), seçip uygula.
- `Kaydet`: config + trust store yaz. Kaydedilmemiş değişiklikle kapatmaya çalışınca sor.

## T3 ve T4'ten gelen bağlayıcı notlar

- **`--ask-args` moduna GEREK YOK.** T3 argüman kutusunu launcher içinde native olarak yazdı,
  T5'e bağımlılık doğmadı. Aşağıdaki `--ask-args` bölümü **iptal edilmiştir**, uygulama.
- Launcher, "yorumlayıcı bulunamadı" diyaloğundaki `Ayarları aç` butonuyla **`Runly.exe` ile aynı
  klasördeki `RunlySettings.exe`**'yi başlatıyor. Yayın düzeninde ikisi yan yana durmalı.
- `GetStatus(config)` 14 uzantıyı sıralı döndürür, doğrudan tabloya basılabilir.
  `UserChoiceOwnerName` yalnızca `NeedsUserChoice` durumunda doludur (bu makinede `.ps1` için
  `"bir Microsoft Store uygulaması"`), diğer hâllerde `null`.
- `ShellRegistrar`'ı `new ShellRegistrar(pathSearcher)` ile kur.
- `InstallResult.Actions` / `UninstallResult.Actions` zaten Türkçe, sonuç diyaloğuna satır satır basılır.
- `RegistryBackup.ListBackups()` "Yedeği geri yükle" listesini besler (`BackupInfo`, yeniden eskiye).
- Kaldırmada "eski hâline döndür" = `new UninstallOptions { RestoreBackup = true }`.
- `OpenWithDialog.ShowForExtension` **modaldir ve UI thread'ini bloklar** — `Form.Handle`'ı owner
  olarak geçir. `false` dönerse (kullanıcı vazgeçti) hata gösterme, satırı olduğu gibi bırak.
- **`.ps1` açıklama metni hazır:** T4 raporunda (`docs/reports/T4-COMPLETE.md`, "`.ps1` UserChoice
  akışı — T5 için GUI metni önerisi" bölümü) tam metin var. Onu **birebir kullan**, yeniden yazma.
- `Runly.Core` ve `Runly.Launcher` **kapalı alanlardır**, dokunma. Senin alanın `src/Runly.Settings/`.

## ~~`--ask-args` modu~~ (İPTAL — T3 kendi native diyaloğunu yazdı, bu bölümü uygulama)

T3, argüman sorma diyaloğunu bu exe'ye devretmiş olabilir. `RunlySettings.exe --ask-args "<scriptPath>"`
çağrıldığında: ana pencereyi **açma**, küçük tek satırlık bir input dialog göster,
kullanıcının girdiğini stdout'a yaz, exit 0; iptal → exit 1.
T3'ün raporunda "kendi native input dialog'unu yazdım" diyorsa bu modu yine de ekle (zararsız,
2. bir yol olur) ama gereksiz süsleme yapma.

## Kurallar

- Config/trust IO'sunu doğrudan yapma — `IConfigStore` / `ITrustStore` kullan.
- Registry'ye doğrudan yazma — `IShellRegistrar` kullan.
- Kurulum/kaldırma sırasında UI donmasın (`async`/`Task.Run`), buton devre dışı + ilerleme metni.
- Yakalanmayan istisna → kullanıcıya anlaşılır Türkçe hata kutusu + log'a stack trace.
- `.csproj`: `net8.0-windows`, `UseWindowsForms=true`, `WinExe`, self-contained yayın,
  **trim kapalı**, `ApplicationHighDpiMode=PerMonitorV2`.

## Kabul kriteri

- `dotnet build -c Release` sıfır warning.
- `dotnet publish src/Runly.Settings -c Release -r win-x64 --self-contained` çalışıyor.
- Elle: pencere açılıyor, tablo dolu geliyor, `node`/`py`/`powershell` ✓ görünüyor,
  `ruby`/`lua` ✗ görünüyor, `.ps1` satırı turuncu ve "Windows'a sor" butonu diyaloğu açıyor.
- Kaydet → `config.json` diske yazıldı, yeniden açınca değerler korunuyor.
- 125% ve 150% DPI'da düzen bozulmuyor.
